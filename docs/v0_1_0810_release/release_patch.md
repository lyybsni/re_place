## Functional
1. Add "place" and "time" for the editing. "Place" shall be a two-level input with ability to free text input. "Time" shall be a month picker. These two items should have higer priority than extracted information.
2. "AI Polish" and "AI Extract" shall have a preview page for user checking, with the metadatas validated by the user. User can also modify all the fields before uploading.
