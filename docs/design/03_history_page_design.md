# History Page Design

## Functionality
Use inbox like display of articles, with the choice of sorting by article time, create time, and maybe others. The user can click on an article to view its details, including the content, images, and any AI-extracted information.
Filters can be "article time", "create time", and so on.

Add a search bar for information about the articles, including title, content, and tags. The search results should be displayed in the same inbox-like format.

## Design
Follow the home page design and re-apply the styles here. The page should be two columns, with the left column displaying the list of articles and the right column displaying the details of the selected article.
