# Home Page Design

## Components

### Title
Use "Re:Place" as the title of the home page, with a subtitle "Your Personal Memory Management Assistant".

### Today's Recommendation City
The left-upper part of the home page will display "Today's Recommendation for the City". This section will show a recommended city based on the user's preferences and past interactions. It will include a brief description, key highlights, and a few recommended places to visit within that city.
The city is from API for fetching. It's below will be a digest of the status of the city, e.g. how many articles have been ingested, some of them are from which topic.

### Topic Recommendation
A list of recommended topics will be displayed by fetch the APIs.
Count should be between 3 to 5.

### Map
See the PRD file for defining the map. Find a useful map library for the front-end. The map should be interactive, allowing users to click on different regions to view more information about that area. The map will also display markers for recommended places and articles related to those places.
> The interactive map should be able to be viewed in the city level. No need to display the streets or buildings, although it can be a plus.
By clicking the map object, the user can see the digest of how many articles are about this place and having some avatars. And the user can enter cities for the same thing.

## Styles
Use a clean and modern design with a focus on usability. The color scheme should be visually appealing and consistent throughout the application. Use responsive design principles to ensure the home page looks good on both desktop and mobile devices.
